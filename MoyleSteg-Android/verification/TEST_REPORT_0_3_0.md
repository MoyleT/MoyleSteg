## 大文件证据与边界

实际随机源为 1,073,741,824 字节；JVM 最大堆 134,217,728 字节。场景耗时 109.50 秒，包含生成、加密及独立回读验证、只读验证、恢复和恢复文件流式哈希，不是手机速度或单独加密速度。源 SHA-256 为 `06e783a40386e4f9fb9a614c83061e37fbd06b991eb3d8cd3a4ba386717c010c`，各次恢复核对一致。合成大文件与私有中间文件已清理。

另有 64 MiB 不可压缩文件在 64 MiB JVM 堆中通过同样的核心流程。SAES 使用文件接口与固定 64 KiB 缓冲；PNG／GIF 仍是受预算控制的图片／载荷数组接口。格式 v1 没有改变，不能由 SAES 流式支持推导出单张 PNG 可以装入 1 GiB。

资源预算测试包括：系统低内存、堆上限、手动范围、任务开始重新检测、未知文件大小、输入变化、清理失败、协作取消、认证后私有副本改变、落盘故障与解压长度。受控故障注入不是现实中发生过磁盘耗尽或介质故障的证据。

只读代码复核未发现本轮可证实的认证绕过；它不能替代正式密码学审计。SAF 导出的新空目标检查和回读校验不提供所有文档提供方上的原子并发禁止替换保证。

主机为 Windows；JDK 21、Kotlin 2.2.21、Gradle 8.13、AGP 8.13.2、BC 1.85.2、SDK 36／Build Tools 35.0.0。所有本轮构建与临时目录在指定工作盘。
