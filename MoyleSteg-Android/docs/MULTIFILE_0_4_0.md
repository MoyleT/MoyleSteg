# 多文件隐写与选择恢复 · Android 0.4.0 / Windows 1.6.0

选择一个文件时沿用原来的单文件格式；选择两个或更多文件时，应用先创建标准 ZIP，再将整个 ZIP 当作原有 PAY1 载荷加密。PNG 像素布局、GIF 扩展封装、SAES、AES-GCM 与口令/密钥派生均保持原有 v1 格式。

## 使用流程

1. 选择 JPG／PNG／GIF 载体，添加一个或多个秘密文件；独立 SAES 不需要载体。
2. 多文件列表可添加、移除、清空，显示已知大小与总数；未知大小会在实际捕获时核对。
3. 图片实际容量预检会完成真实 ZIP 打包，展示原始总量、ZIP 大小及现有容量/扩容结果。预检不预留资源。
4. 所有成员用同一个口令或密钥统一加密。保存后的成品会回读认证。
5. 新版恢复完成外层认证后，检查并读取 ZIP 全部成员，显示原名、大小和选择项。此时未向 Download 写出成员。
6. 选择全部或部分保存到 Download；各项使用独立的新文件名，已存在文件不覆盖。每项可通过系统打开方式选择器查看。

单文件以及用户自己的普通 ZIP 保留原来的自动 Download 流程，不自动拆开。多文件包可显式另存完整 ZIP。旧版软件会恢复名为 `MoyleSteg-files.zip` 的标准压缩包，用户解压后可取得原文件；重复名字位于不同编号目录内。

## 失败、取消与私有数据

多文件保存逐项提交，不是跨文件事务。已经保存的项立即记录成功；取消、磁盘错误或权限拒绝会保留成功项，剩余项可直接重试，不重复保存成功项，也不需要重新输入凭据。

私有认证 ZIP 在当前结果保留，以支持选择其他成员或另存完整包。清空结果、更换输入、离开该任务或应用下次进程启动会清理私有文件；公共 Download 文件由用户管理。不能保证被系统杀进程后继续恢复任务，也不承诺物理擦除。

旧 Android 的权限回复、保存位置选择器回复都绑定到发起时的结果；结果或成员选择发生变化后，过时的回复不导出当前新数据。

## 跨端受限 ZIP 协议

- 外层认证的文件名为 `MoyleSteg-files.zip`；检测仅依据 ZIP EOCD 的精确 ASCII 注释 `MOYLESTEG-BUNDLE-V1`，不依据文件后缀。
- EOCD 结尾必须恰为文件结尾；单磁盘，成员数一致且为 1–100，中央目录不超过 128 KiB，并紧邻 EOCD。禁止 ZIP64。
- 成员顺序路径为 `0001/<原文件名>`、`0002/<原文件名>` 等，从 1 连续编号。文件名为严格 UTF-8，原名最多 180 个 UTF-8 字节，须通过共同的 Windows/Android 安全 basename 规则。
- 仅普通文件，允许重复原名；禁止目录、符号链接、设备、路径穿越、保留设备名、绝对路径及流名称。只支持 STORED 或 raw DEFLATE。
- 必须设置 UTF-8 标志；只允许 UTF-8 和 data descriptor 标志（掩码 `0x0808`）。不允许 ZIP 自身加密、额外字段或成员注释。
- 本地记录连续排列；本地头与中央目录的元数据一致。可接受 12 字节无签名或 16 字节有签名的数据描述符，CRC、压缩/展开长度必须一致。
- 先以受限读取检查 EOCD、目录长度和数量，再解析受限元数据、验证名称及压缩/展开长度；展开前确认总量预算，读取文件内容时按不超过 64 KiB 分块并再次强制上限。中央目录元数据最多 128 KiB，EOCD 定位最多读取文件末尾 65,557 字节。
- 清单检查完整读取每一项并计算 CRC32/SHA-256。选择恢复写入随机私有文件并校验预期大小及 SHA-256，随后用既有 Download 提交层保存并独立回读。
- 精确标记存在但结构损坏时拒绝；未标记 ZIP 保持普通单文件行为。

## 资源边界

手机图片隐写原始总量和 ZIP 都不得超过 32 MiB；SAES 两者都不得超过 1 GiB。ZIP 头与索引同样占用上限，因此原始文件恰好达到上限时仍可能无法打包。PNG／GIF 和设备内存预算继续生效。

应用先捕获每个源文件并逐块复核，再打包并复核保存后的 ZIP；这可以拒绝可观察到的内容变化，不是多个源文件在同一时刻的系统快照。持续更新的文件应先稳定导出。

临时副本及包可能同时存在；流式 ZIP 不等于整个图片处理流程都流式化。加密保护成员内容，不能保证外层图片的隐写不可检测。
