# Dependencies and attribution

The Android build resolves Kotlin, AndroidX, coroutines and Bouncy Castle from their
published repositories. Their existing licenses apply. The source archive includes
the official Gradle Wrapper JAR generated by Gradle 8.13 (Apache-2.0). It does not
include an SDK, JDK, application dependency binaries, fonts, Python or Windows runtime.

Robolectric 4.16, JUnit 4.13.2 and kotlinx-coroutines-test 1.10.2 are host test
dependencies only; they are not packaged in the normal Android application.

Bouncy Castle is used only through its lightweight SCrypt API; AES-GCM and HMAC are
obtained from JCA. No BouncyCastleProvider is registered globally. See the upstream
license: https://www.bouncycastle.org/licence.html

`tools/reference/desktop_1_4_1.py` is the user's supplied original desktop source,
kept unchanged for compatibility tests. Its provenance is recorded; this package
has not assigned a new license to that existing source.

All bundled test payloads and image samples are synthetic. The fixture key is
intentionally public and unsuitable for real secrets. No user's PDF is included.
